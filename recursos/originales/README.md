# Originales protegidos

Archivos de fuente primaria tal como se descargaron, con licencia verificada. **No se editan nunca.**

- Cada archivo se registra en `SHA256SUMS` y en el manifiesto de [`docs/ASSETS.md`](../../docs/ASSETS.md).
- Verificación: `sha256sum -c SHA256SUMS`, desde esta carpeta.
- Claude Code tiene denegados `Edit` y `Write` sobre esta carpeta (`.claude/settings.json`).
- Para trabajar con un original, se copia a `../aprobados/`.
